An entry for the [make.fun](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7) bounty **"Describe Your Ex in One Word"**: sum up an ex in exactly one word.

## The entry

> Recalled

One word, 8 characters. The ex is a defective product pulled from the shelves — and "recalled" also means remembered, so the word carries the memory of the ex and the verdict on it at once.

## How it works

`main.ts` (Node 22, stdlib only, no network, no secrets) scores three candidate words against the judge's five published criteria — verdict on an ex, comic punch, surprise, craft, recognition — and writes the winner to `/output/entry.txt`.

Run it locally:

```sh
node main.ts
```
